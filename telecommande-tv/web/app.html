🎮 Télécommande Wi-Fi

Un navigateur web n'a pas le droit d'ouvrir la connexion sécurisée spéciale qu'exige la télé (comme le fait l'appli Google TV). Une petite passerelle sur un ordinateur du même Wi-Fi fait l'intermédiaire.

  1. Sur l'ordinateur : installe Python (gratuit, python.org), puis double-clique sur Lancer-passerelle-Windows.bat (Mac/Linux : python3 passerelle_tv.py).
  2. La télécommande s'ouvre sur l'ordinateur. Sur le téléphone, scanne le QR code affiché ou tape l'adresse indiquée (ex. 192.168.1.20:8765).
  3. « Chercher ma télé », puis tape le code qui s'affiche sur la télé. C'est fait une seule fois.
