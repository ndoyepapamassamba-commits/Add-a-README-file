# 📺 09 · Series production

Everything that makes episode 7 still feel like episode 1.

## Planned skills

- [ ] `series-bible` — builds `series-bible.md`: premise, world rules, characters, episode engine, format
- [ ] `series-season-arc` — season arc and A/B/C plots, midpoint, finale; hooks and cliffhangers per episode
- [ ] `series-episode-breakdown` — episode outline: cold open, act breaks, scene list, runtime budget → feeds screenwriting
- [ ] `series-continuity` — continuity log across scenes and episodes (wardrobe, props, injuries, time, character locks) and a checker
- [ ] `series-production-tracker` — per-episode status board and asset registry with fixed IDs (characters, locations, voices)
- [ ] `series-packaging` — recaps, intro/outro, episode titles, thumbnails and descriptions in a consistent format

## Inputs → outputs

`brief.md` + `style-bible.md` → `series-bible.md`, episode outlines, continuity log, tracker.
