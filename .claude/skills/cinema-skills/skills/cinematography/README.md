# 📷 03 · Cinematography

How each shot looks: frame, lens, movement and light — described precisely
enough for a camera crew or an image/video model.

## Planned skills

- [ ] `camera-framing` — shot sizes, composition, headroom/lead room, aspect-ratio choice, recurring frame motifs
- [ ] `camera-lens-and-movement` — focal length and depth-of-field choices, camera moves and their motivation, support (tripod, dolly, handheld, gimbal)
- [ ] `camera-lighting` — lighting plans: key/fill/back, motivated sources, contrast ratios, colour temperature, time of day
- [ ] `camera-look-design` — converts the style bible into a concrete camera + light vocabulary (and prompt blocks for AI generation)
- [ ] `camera-coverage-check` — verifies the shot list covers every beat, keeps the axis, and cuts together

## Inputs → outputs

`shots.csv` + `style-bible.md` → per-shot camera and lighting specs (columns in `shots.csv`), lighting diagrams/notes.
