# ✨ 08 · Titles & VFX

Typography on screen and the invisible (or visible) effects work.

## Planned skills

- [ ] `vfx-compositing` — keying, masks, overlays, sky replacement, screen inserts
- [ ] `vfx-cleanup` — paint-outs, stabilisation, deflicker, fixing AI artifacts (warped hands, text, morphing)
- [ ] `vfx-transitions` — motivated transitions, light leaks, film burns — only where the style bible allows them
