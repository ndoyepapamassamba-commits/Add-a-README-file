# ✍️ 01 · Screenwriting

From an idea to a locked script in plain-text [Fountain](https://fountain.io) format.

## Planned skills

- [ ] `script-premise` — idea → premise, logline, theme/controlling idea, genre promise
- [ ] `script-structure` — beat sheet in a chosen model (three-act, sequence approach, five-act, hero's journey) with page/time targets
- [ ] `script-characters` — character profiles: want vs. need, flaw, arc, relationships, distinct voices
- [ ] `script-scene-writer` — writes scenes in Fountain from beats; every scene has a goal, conflict and turn
- [ ] `script-dialogue-pass` — subtext, compression, distinct voices, removes on-the-nose lines
- [ ] `script-doctor` — diagnoses structure, pacing and clarity problems; gives prioritised notes
- [ ] `script-short-form` — micro-scripts for 30–120 s shorts and vertical episodes (hook in the first seconds, one turn, button)
- [ ] `script-format-tools` — Fountain lint, scene numbering, conversion to PDF/FDX, page-count → screen-time estimate

## Inputs → outputs

`brief.md` → `script/epNN.fountain` (scene numbers match shot-list IDs, `[[notes]]` carry intentions for directing and sound).
