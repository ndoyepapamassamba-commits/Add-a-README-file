# Visual acceptance ledger — worked example (anonymized)

Target: `concepts/harbor-target.png`. It is an imagegen target, not an engine
capture. Reviewer is a separate fresh-context agent using a gated
composition/light/material/detail ladder. No subjective gameplay acceptance
is inferred.

1. First rendered scene: **2.5/10**, composition gate blocked. Missing harbor
   depth, flat glowing facade, repeated black paving marks.
2. Revised capture: **2.8/10**, gate blocked. Props improved but cropped
   crane/flat background persisted.
3. Evidence correction: duplicate older capture detected. Reviewer explicitly
   declined to count unshown changes as a failed implementation. No new score.
4. Structural change: generated cloud sky, bounded water with sky environment
   and wave normals; framed/grounded crane; ship masts; rear quays; authored
   corrugated awning; real paving slabs. Round 5: **3.0/10**; continuous quay
   bands and primitive asset massing still block target match.
5. Removed continuous rear strips, localized docks, reduced distant detail
   contrast, rebuilt awning as a sloped corrugated mesh, moved composition
   closer to target. Round 6: **3.0/10**. Direction improved; scene still
   sparse, materials and models substantially less detailed than target.
6. Final structural pass adds an original multi-deck carrier behind the shop
   and a stronger right-hand ship silhouette, adjusts lighting, and retains
   known mismatches rather than lowering target.

The visual target has not passed. Do not describe this release as close to
the concept. The target is retained for further work. The complete playable
mission and publication are independent deliverables.

## Final independent result

The final bounded review remained **3.0/10**, with the first gated visual
tier still unmet. The reviewer confirmed a plateau across the structural
revisions. Remaining issues: large planar cargo massing, duplicated vessel
construction, texture-driven rather than convincingly physical wear,
insufficient distance separation and material detail, and simpler foreground
construction. No gameplay, control, animation or performance verdict was
inferred from the stills. The concept is preserved unchanged; the release is
a functional playable deliverable with this art limitation recorded.

---

Why this ledger works: numbered rounds, one cause per round, scores that are
allowed to stay flat, an independence incident (round 3) that proves the
reviewer is not a rubber stamp, and a closing paragraph that forbids
success language. Copy the shape, not the scores.
