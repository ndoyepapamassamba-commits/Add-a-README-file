# Contributing

Issues and pull requests are welcome for clearer decisions, useful QA steps, current documentation links, and tested portability improvements.

- Keep `SKILL.md` concise. Put mode-specific detail in the relevant `references/` file and link it from the entry point.
- Write for a new user's brief. Do not hardcode one project's aspect ratio, runtime, brand, provider account, machine path, or paid budget as a universal default.
- Never include client media, proprietary source files, credentials, account details, or private project histories. Link official tool documentation instead of copying it.
- Mark observed results separately from estimates. Explain which Blender/Unreal versions, OS, hardware, or agent host you actually tested.
- Validate YAML frontmatter, relative links, and a fresh-agent setup/readiness scenario. A syntax check alone is not a render test.

By contributing, you agree that your contribution is distributed under the repository's MIT license. Third-party tool and asset terms remain separate.
