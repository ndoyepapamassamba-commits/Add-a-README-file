Comment ça marche

  1. Essayez gratuitement. Ouvrez l'application et utilisez la version gratuite, sans compte ni inscription.
  2. Payez le pass par Wave. Dans la boutique, envoyez le montant exact affiché : le paiement est reconnu tout seul.
  3. Activez en un geste. Sur la page de votre commande, touchez « Ouvrir l'application et activer ».

Installer une application sur votre téléphone

Sur Android (Chrome)

  1. Ouvrez l'application dans Chrome (bouton « Essayer gratuitement »).
  2. Touchez « Installer » dans l'application, ou le menu ⋮ en haut à droite.
  3. Choisissez « Installer l'application » ou « Ajouter à l'écran d'accueil ».

Sur iPhone (Safari)

  1. Ouvrez l'application dans Safari.
  2. Touchez le bouton Partager (carré avec une flèche vers le haut).
  3. Choisissez « Sur l'écran d'accueil », puis « Ajouter ».

L'icône apparaît sur votre écran d'accueil, comme une application normale. Pour les applications hors ligne, plus besoin d'Internet après la première ouverture. Sur iPhone, activez le pass depuis l'application installée : copiez le lien de la page de votre commande, puis collez-le dans l'écran du pass de l'application.

Questions fréquentes

Mes données sont-elles envoyées sur Internet ?

Teranga Factures, PouletPilot, Carnet Élevage, Carnet Boutique, Carnet du Tailleur, Teranga Vitrine, Budget Famille, Champ Pilot, Calcul Chantier, Carnet Entretien, Teranga Partage Frais, Anglais du Métier et Lecture Facile : non, ce que vous saisissez reste sur votre téléphone ; seule la vérification du pass passe par Internet. Pensez à faire une sauvegarde de temps en temps (Réglages de l'application). AccordAI, ColisPreuve, Tontine Claire et Rendez-vous Pro : ce que vous partagez par lien passe par notre serveur pour que l'autre personne le voie ; seules les personnes qui ont le lien y ont accès, et c'est effacé 180 jours après la dernière activité.

Comment activer mon pass après le paiement ?

Sur la page de votre commande payée, touchez « Ouvrir l'application et activer ». Vous pouvez aussi copier le lien de cette page et le coller dans l'écran du pass de l'application. Un mode d'emploi en PDF est fourni avec chaque pass.

Et si je change de téléphone ?

Restaurez votre sauvegarde sur le nouveau téléphone, puis activez à nouveau avec le même lien de commande.

Le pass se renouvelle-t-il tout seul ?

Non. Rien n'est prélevé automatiquement. À la fin d'un pass, vos données restent sur votre téléphone et vous reprenez un pass seulement si vous le voulez.

Puis-je les utiliser sur un ordinateur ?

Oui, les applications fonctionnent aussi dans le navigateur d'un ordinateur, et peuvent y être installées avec Chrome ou Edge.
