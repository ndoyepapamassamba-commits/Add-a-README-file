Comment produire une vidéo

  1. Réglages : colle ta clé OpenRouter, fixe le plancher (l'application s'arrête avant que la clé descende dessous), mets le nom et le pseudo de ta chaîne.
  2. Banque : les sketchs sont rangés du plus drôle au moins drôle (note du jury). Clique « les meilleurs non tournés » (3 par défaut), puis « Envoyer la sélection en production ». Le bouton « Prompts » montre et copie le prompt image et le prompt vidéo de chaque sketch.
  3. Production : fixe le plafond de dépense (1 $ suffit pour 3 sketchs), puis « Démarrer ». L'application génère l'image, puis le clip animé, puis le contrôle IA. Un clip « à revoir » peut être refait d'un clic.
  4. Montage : coche les clips (3 suffisent avec les transitions), ajoute si tu veux des gags 3D libres de droit, puis « Créer la compilation ». La vidéo fait plus de 62 s (monétisation TikTok).

Coûts

Un sketch ≈ 0,25 à 0,30 $ (image + clip de 10 à 12 s + contrôle). Une compilation de 3 sketchs avec transitions ≈ 0,90 $. Le montage lui-même est gratuit : il est calculé dans ton navigateur.

Gags 3D libres de droit

L'application affiche le crédit à l'écran ; ajoute aussi dans la description TikTok : « Extraits 3D : Big Buck Bunny, Caminandes 3 — (CC) Blender Foundation | studio.blender.org ». Garde les extraits courts (TikTok peut juger « non original » un contenu dominé par des extraits).
