## Comment faire
1. Récupère la photo (voir « Où sourcer » dans le README principal) ou **prends-la toi-même** sur fond blanc.
2. Renomme-la `p1.jpg`, `p2.jpg`, etc. et mets-la dans ce dossier.
3. C'est tout : la photo s'affiche automatiquement sur la boutique.

> Tant qu'une photo manque, le produit affiche un repli propre (icône + couleur). Rien ne casse.
>
> **Conseil qui fait vendre :** photo carrée, lumière du jour, fond clair et uni. Une bonne photo peut doubler tes ventes.
