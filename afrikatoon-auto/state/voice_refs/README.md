# Voix de référence (Chatterbox)

Chaque fichier `<PERSONNAGE>.wav` (~16 s) sert de modèle de voix à Chatterbox (`afrikatoon/voices_local.py`).

Origine : corpus **African Accented French** (OpenSLR SLR57, https://www.openslr.org/57/), licence
**Apache 2.0** (usage commercial autorisé), enregistrements de locuteurs du Cameroun, du Gabon, du Tchad
et du Congo (session CA16). Extraits choisis par hauteur de voix :

| Fichier | Locuteur CA16 | Hauteur moyenne |
|---|---|---|
| MAMAN_NOUNOU.wav | 028 | 168 Hz (femme, voix posée) |
| COUMBA.wav | 088 | 199 Hz (femme jeune, très propre) |
| PETIT_MAMADOU.wav | 068 | 236 Hz (rendue plus aiguë au montage, ×1,18) |

Pour une voix plus proche de vos vidéos : remplacez le fichier par 10-20 s d'une voix dont vous avez
les droits (la vôtre, un comédien sous contrat).
