# Veille — vidéo 3D en HTML et animation d'images (14/10/2026)

Demandes de l'utilisateur : « le bac à sable doit réaliser des vidéos 3D de 15 s par prompt », « faire du HTML et le
traduire en MP4 », « animer une image fixe », « créer une veille sur le HTML vidéo 3D ». Règle maison : ce qui tourne
chez nous est sous MIT, Apache-2.0 ou BSD.

## 3. Animer une image fixe (architecture des outils étudiés)
- **Parallaxe 2.5D (Depthflow, 3D Ken Burns)** : carte de profondeur + caméra virtuelle ; chaque pixel décalé selon sa
  profondeur. Profondeur : [Depth Anything V2 Small](https://huggingface.co/onnx-community/depth-anything-v2-small)
  (**Apache-2.0** lue sur la fiche) dans le navigateur via transformers.js 4.3.1 (**Apache-2.0**).
- **Champs de mouvement eulériens** ([Holynski et al., CVPR 2021](https://openaccess.thecvf.com/content/CVPR2021/papers/Holynski_Animating_Pictures_With_Eulerian_Motion_Fields_CVPR_2021_paper.pdf)) :
  un champ de vitesse constant ; image = mélange d'un déplacement avant et arrière pondéré par t/T → boucle sans couture.
- **Animated Drawings** ([Meta, papier](https://arxiv.org/pdf/2303.12741v2), MIT) : détection → masque → squelette →
  maillage 2D déformé par ARAP → mouvement retargeté. Notre `coeur/studio/actor/arap.ts` reprend ce schéma.
- **IA générative image→vidéo** : Wan 2.2 (Apache-2.0, GPU 24 Go) ; LTX-2.x (licence maison) ; API payées à l'usage
  déjà recensées (voir journal) → option premium, jamais requise.

## 4. Ce qui est construit à partir de cette veille
- `coeur/videogen/imageMotion.ts` + `navigateur/videogen/imageGL.ts` : parallaxe avec recherche de surface
  (occultations), travelling physique, effet vertigo, eulérien en boucle, pinceau de mouvement, pluie, neige, poussière,
  brume, rayons, grain, vignettage, bandes cinéma ; `depth.ts` : Depth Anything V2 local, repli heuristique.
- `coeur/videogen/{plan,animate,assets,bpy}.ts` : idée / texte / image → plan validé → poses image par image →
  scène commune → **Blender** (script bpy + exports USD / glTF) ; le même plan est rendu en **HTML/WebGL** pour l'aperçu
  et le MP4 rapide.
- Mesure Blender (conteneur, 4 cœurs, Cycles CPU, 480×270, 12 i/s) : 48 images en 372 s (≈ 7,7 s/image) → le rendu
  HTML/WebGL est la voie rapide par défaut, Blender la voie qualité (pont local avec GPU ou conteneur).

Méthode retenue (code : `coeur/videogen/videoDepth.ts`, `navigateur/videogen/{videoScene,scenePage,audioCopy}.ts`,
`outils/video-scene-page.ts`) :
1. **Bande nette** détectée par la netteté des lignes (format vertical « vidéo posée sur sa copie floue ») → profondeur
   mesurée sur la scène seulement, la copie floue devient un plan lointain.
2. **Changements de plan** détectés (histogramme + différence) → le suivi repart de zéro, aucune profondeur ne
   traverse une coupure, pas de mélange de cartes entre deux plans.
3. **Suivi temporel** : flot optique par blocs, recalage échelle/décalage (moindres carrés), filtre temporel sauf là où
   l'image change, médiane 3×3 (taches), dilatation du premier plan d'un texel (l'étirement tombe dans le fond).
4. **Rendu** : chaque sommet glisse le long de SON rayon (au repos = pixels d'origine) ; seuls les triangles réellement
   étirés à l'écran (`fwidth`) sont peints avec la couleur du plan arrière.
5. **Page autonome** : vidéo d'origine intacte + atlas PNG sans perte + AAC d'origine + three.js + mp4-muxer en base64 →
   hors ligne ; export MP4 image par image (WebCodecs), son recopié octet pour octet (vérifié par test).

Mesures sur la vidéo 041701 (1080×1920, 30 i/s, 12,3 s, conteneur sans GPU) : bande nette détectée lignes 514–1408,
coupure à 10,07 s, 185 cartes en 163 s (modèle CPU), page de 24,7 Mo ; export dans le Chromium de test (logiciel, VP9) :
369 images en ≈ 8–9 min, son AAC identique à l'octet près. Limite honnête : le Chromium du conteneur ne décode ni
n'encode le H.264 ; dans Chrome / Edge chez l'utilisateur, l'export est en H.264 et la lecture de l'original directe.

Méthode (code : `outils/scene_layers.py`, `outils/troupe-plates.py`, `navigateur/videogen/videoScene.ts`) :
premier plan = personnes, véhicules, bateaux, animaux (élargi de 1,2 %) → LaMa reconstruit le décor dessous → Depth
Anything V2 donne la profondeur du décor reconstruit → la page 3D dessine DEUX maillages : le décor reconstruit (sa
profondeur, ciel qui défile en boucle eulérienne, eau qui ondule, arbres qui se balancent) et le premier plan (pixels
d'origine). Quand la caméra bouge, l'écart derrière un personnage montre le vrai décor reconstruit ; au repos l'image
est celle d'origine. Au-delà du cadre : bords prolongés. Décors du projet : 191 traités en lot (≈ 10 s chacun),
embarqués dans l'app avec leurs couches.
