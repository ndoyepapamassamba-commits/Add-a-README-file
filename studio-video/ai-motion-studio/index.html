    Où sont vos données
    • Ce navigateur : médias, projet en cours, historique (IndexedDB).
    • Fichier projet : tout, pour rouvrir ailleurs.
    • Serveur local (s'il est lancé) : vidéos reçues des fournisseurs payants, effacées au bout de 24 h.
    • Fournisseurs : leurs liens sont temporaires ; l'application les télécharge aussitôt.

    MASSAMBA AI MOTION STUDIO — mode d'emploi
    
    
      
      
    • 1. Générez : Image → vidéo (importez une image, décrivez le mouvement) ou Texte → vidéo (décrivez la scène). Choisissez un moteur gratuit ; un compte Hugging Face gratuit augmente le quota.
      • 
      
    • 2. Storyboard : découpez votre scénario en scènes, générez-les une par une ou en « Film complet » (confirmation demandée), puis assemblez.
      • 
      
    • 3. Personnages : la nouvelle troupe est déjà là ; une fiche de continuité est ajoutée aux consignes.
      • 
      
    • 4. Montage : vraies vidéos dans la timeline, découpe, transitions, textes, sous-titres, effets, keyframes.
      • 
      
    • 5. Son : musique, bruitages, voix au micro ou générée, son d'origine des vidéos.
      • 
      
    • 6. Exportez : MP4 H.264/AAC validé (dimensions, durée, codec, son) ou WebM ; sauvez le projet pour le rouvrir.
      • 
    
    
    
    Raccourcis (Montage) : Espace lecture · ←/→ ±0,5 s · S découper · K keyframe · Ctrl+D dupliquer · Suppr retirer · Ctrl+Z/Ctrl+Y.
    
    
    Mode démo : animation locale marquée « DÉMO », jamais présentée comme une génération IA.
